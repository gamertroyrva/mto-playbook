Phase 3 — Wants Phase / Practice Runs
Task Task Description Task Steps Why Do This
Capture Practice Run Data The starting point of every practice run — pulling the current wants list and a fresh TradeMaximizer run into local files for processing.
  1. Create a new practice run subfolder on your computer.
  2. Open a text editor and create two blank text files.
  3. Go to the math trade's "edit info" page on OLWLG.
  4. Click "click here to read the online wants submissions" — select all, copy, paste into the first file, save.
  5. Find the line "If you want to test (using the wants submitted so far) run the JavaScript version of TradeMaximizer click here" and click it.
  6. On the page that opens, click Run. Results scroll on the page — select all, copy, paste into the second file, save.

Both files capture a snapshot of the trade at this exact moment — what's been submitted, and what the algorithm would produce if the trade ended right now.

Everything downstream — the tracker, the communication, the anomaly review — depends on these two files.
Update the Results Tracker A handful of numbers, pulled from the two captured files, drive a running spreadsheet of submission and trade statistics across all practice runs.
  1. Open the Results Tracker spreadsheet.
  2. Add a new row for this practice run.
  3. Enter the manual input fields — Missing Wants, Missing Users, Games w/ Trades — sourced from the two captured files.
  4. The spreadsheet automatically calculates Submitted Users, Submitted Games, percentages, and Users w/ Trades.

A few inputs produce a rich, comparable view of how the trade is shaping up over time — submission rates climbing, trade outcomes improving.

This data feeds directly into the communication that follows.
Formulate Results Communication Draft the practice run update for participants — a short, encouraging summary of where the trade stands, built from the tracker's numbers.
  1. Open the standing communication template (Google Doc).
  2. Note the time the practice run was captured.
  3. Pull the four headline numbers from the Results Tracker: submitted users (of total), submitted games (of total), users who would trade, games that would trade.
  4. Write 1-2 sentences of situational framing — acknowledge the milestone, speak to what's changed since the last update.
  5. Confirm the boilerplate (practice/not-final disclaimers, link to the OLWLG pending results summary) is intact.

Participants want to see momentum — a quick, encouraging snapshot keeps energy up during the submission window.

The disclaimers matter: these are practice numbers, and nobody should mistake them for final results.
Upload Results to OLWLG Before the communication goes out, the freshly captured results need to be uploaded to OLWLG so the "pending results summary" link in that communication actually reflects this practice run.
  1. On the OLWLG "edit info" page, scroll to "Upload Official (TradeMaximizer) Results."
  2. Click the upload tool link.
  3. Browse to the results file saved on your computer (from Capture Practice Run Data).
  4. Click Upload.
  5. Click through to the "pending results summary" page and peek at it for a minute or two to confirm it updated.

The communication points participants to a live OLWLG page — if that page isn't refreshed first, participants clicking through will see stale (or no) results.

This step makes the link in the communication actually mean something.
Send Results Communication Post the formulated communication to the community.
  1. Paste the formulated communication into the Discord "updates" channel.

This is the moment the practice run becomes visible to the community — getting it out is treated as a priority, even at odd hours, because participants check in on their own schedule.
Perform Anomaly Review A mandatory quality check — run the anomaly detector against the practice run results to catch likely mistakes before they become a pattern.
  1. Run the anomaly detector program against the captured results.
  2. Review flags for duplicate-protection issues (e.g., someone receiving multiple copies of the same item).
  3. Review flags for significant value mismatches between what a participant gives and receives.

Most flags turn out to be participants who know exactly what they're doing — but occasionally a flag catches a real mistake while there's still time to fix it before the final run.

This is the organizer's responsibility to the trade's integrity, not optional.
Review Pending Results Summary A person-by-person look at the practice run's outcomes — checking in on how individual participants, especially newcomers, are faring.
  1. Open the OLWLG pending results summary.
  2. Look through individual participants' results, paying particular attention to newcomers.
  3. Confirm new participants received trades and that those trades look reasonable.
  4. Engage with participants about their results where it feels natural (e.g., on Discord).

New participants are taking a leap of faith on their first trade.

Seeing that it worked out for them — right there in their first practice run — builds the kind of community that keeps people coming back.
Monitoring & Nudging Submissions An ongoing thread throughout the Wants Phase — keeping track of who has and hasn't submitted, and nudging the ones who haven't, with the urgency and approach shifting as deadlines approach.
  1. Periodically check the OLWLG Users page for submission status.
  2. Sort the Users page by Item Count (descending), then by Submitted Wants — this surfaces non-submitters with the most items in the trade.
  3. For participants on Discord (the large majority in a local trade), reach out personally — a DM, a check-in.
  4. For the remaining holdouts, use the "Geekmail the N users who have not submitted" link — review and prune the recipient list to avoid double-reaching anyone already contacted personally.
  5. Repeat as the deadline approaches, with personal outreach increasingly focused on whoever remains with the highest item count.

Not all non-submitters are equal — someone with 100 items in the trade not submitting affects far more loops than someone with 4. Sorting surfaces who matters most to reach.

The mix of personal and broad-brush outreach respects both the organizer's time and participants' patience. As the list shrinks, the organizer ends up rooting for the last few — sometimes the trade reaches 100% submission, sometimes it doesn't, but the effort is what closes that gap as much as possible.
